# Meu Portfólio Acadêmico

## Sobre o projeto

Este repositório foi criado com o objetivo de desenvolver meu primeiro portfólio acadêmico durante o curso de Ciência da Computação. A ideia é criar uma página na internet onde eu possa apresentar um pouco sobre mim, meus estudos e os projetos que desenvolver ao longo da faculdade.

Como estou no primeiro semestre, ainda estou aprendendo os conceitos básicos da área de tecnologia e conhecendo as ferramentas utilizadas no desenvolvimento de software. Por isso, este projeto também será uma forma de colocar em prática o que estou aprendendo e acompanhar minha evolução durante o curso.

## Objetivos do projeto

O principal objetivo é aprender a organizar e apresentar meus trabalhos acadêmicos de maneira simples e organizada. Além disso, pretendo utilizar este portfólio para reunir os projetos desenvolvidos nas disciplinas da faculdade, facilitando o acesso aos trabalhos e permitindo que outras pessoas conheçam um pouco do que estou estudando.

Outro objetivo é aprender a utilizar ferramentas importantes para a área de programação, como o Git e o GitHub, que permitem armazenar códigos, registrar alterações e compartilhar projetos.

## Desenvolvimento

O projeto será desenvolvido aos poucos, conforme eu adquirir novos conhecimentos durante o curso. Inicialmente, pretendo criar uma página utilizando HTML para estruturar o conteúdo e CSS para melhorar sua aparência.

Também pretendo organizar os arquivos e os projetos em repositórios no GitHub, mantendo os trabalhos separados por disciplina quando necessário. Dessa forma, ficará mais fácil encontrar os materiais e acompanhar o desenvolvimento de cada atividade.

Após criar a página, pretendo publicá-la utilizando o GitHub Pages, permitindo que meu portfólio seja acessado pela internet.

## Ferramentas utilizadas

- **GitHub:** para armazenar meus projetos e compartilhar meus códigos.
- **GitHub Desktop:** para facilitar o gerenciamento dos repositórios e o registro das alterações.
- **Git:** para controlar as versões dos arquivos e acompanhar as mudanças realizadas no projeto.
- **HTML:** para estruturar os elementos da página.
- **CSS:** para definir o visual e a organização dos elementos da página.
- **GitHub Pages:** para publicar o portfólio na internet.

## Aprendizado esperado

Com o desenvolvimento deste projeto, espero compreender melhor como funciona a criação de uma página web, aprender a organizar meus arquivos e desenvolver mais familiaridade com o Git e o GitHub.

Também quero utilizar o portfólio para registrar minha evolução acadêmica, acrescentando novos projetos e conhecimentos conforme avanço no curso de Ciência da Computação.

Por ser um dos meus primeiros projetos, sei que ainda há muito a aprender e melhorar. A intenção é continuar desenvolvendo e atualizando este portfólio ao longo da faculdade.
