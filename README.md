# Meu Portfólio Acadêmico

## Sobre o projeto

Este repositório foi criado durante a disciplina BootCamp I, do curso de Ciência da Computação, com o objetivo de desenvolver meu portfólio acadêmico e apresentar minha evolução ao longo da graduação.

## Objetivos

- Apresentar minha trajetória como estudante de Ciência da Computação.
- Organizar e divulgar meus projetos acadêmicos.
- Reunir links para os repositórios das disciplinas.
- Desenvolver conhecimentos em HTML, CSS, Git e GitHub.
- Publicar meu portfólio utilizando o GitHub Pages.

## Organização

- `index.html` — estrutura e conteúdo da página principal.
- `style.css` — estilos e aparência do site.
- `README.md` — documentação do projeto.

## Tecnologias e ferramentas

- HTML
- CSS
- Git
- GitHub
- GitHub Pages

## Objetivo futuro

Utilizar este portfólio para documentar meus aprendizados, apresentar os projetos desenvolvidos durante a graduação e acompanhar minha evolução na área de tecnologia.
